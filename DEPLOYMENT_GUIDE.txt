🚀 INSTALLATION & DEPLOYMENT
════════════════════════════════════════════════════════════════════════════════

METHOD 1: Direct Deployment (Recommended)
──────────────────────────────────────────────────────────────────────────────

1. Copy the entire folder:
   From: dist\OfflineIndustrialIntelligence\
   To:   C:\Program Files\OfflineIndustrialIntelligence\
   (or any location on your deployment machine)

2. Create shortcut (optional):
   Right-click OfflineIndustrialIntelligence.exe
   → Send To → Desktop (create shortcut)

3. Run:
   Double-click OfflineIndustrialIntelligence.exe
   OR
   Click desktop shortcut


METHOD 2: USB Distribution
──────────────────────────────────────────────────────────────────────────────

1. Copy folder to USB:
   dist\OfflineIndustrialIntelligence\ → USB:\

2. On target machine:
   Copy from USB to hard drive (C:\temp\ or any location)

3. Run:
   Navigate to copied folder
   Double-click OfflineIndustrialIntelligence.exe


METHOD 3: ZIP Archive Distribution
──────────────────────────────────────────────────────────────────────────────

1. Create archive:
   1. Download 7-Zip or WinRAR (if not installed)
   2. Right-click: dist\OfflineIndustrialIntelligence\
   3. Add to archive → OfflineIndustrialIntelligence.zip
   4. Compressed size: ~25-30 MB

2. Distribute ZIP file:
   - Email
   - Share drive
   - Internal portal

3. User extracts:
   Extract OfflineIndustrialIntelligence.zip anywhere
   Double-click OfflineIndustrialIntelligence.exe
