| Architecture Layer   | Frontend Sees                    | Why                                            |
| -------------------- | -------------------------------- | ---------------------------------------------- |
| Data Profiler        | Data health, column roles, stats | Engineers trust data only if health is visible |
| Rule Engine          | Rule results + explanations      | Maintenance needs explain ability               |
| ML Engine            | Anomaly flags, confidence        | Not model internals                            |
| Insight Orchestrator | Final merged insights            | Single source of truth                         |
| Dashboard Blueprint  | KPIs, charts, layouts            | UI rendering logic                             |
| Local SQLite         | Read-only views                  | Offline, auditable                             |

| Backend Layer        | Frontend Responsibility     |
| -------------------- | --------------------------- |
| Ingestion            | ❌ Hidden                    |
| Feature Store        | ❌ Hidden                    |
| Profiler             | ✔ Data health, column roles |
| Rule Engine          | ✔ Rule explanations         |
| ML Engine            | ✔ Anomaly summaries         |
| Insight Orchestrator | ✔ Final insights            |

| Local SQLite         | ✔ Read-only access          |


Frontend Rules (Ingestion)

All users can upload data

Users must declare data source type

Ingestion is explicit, manual, and versioned

System shows run ID, summary, and status

No raw data preview by default

The frontend uses a persistent left sidebar with a central workspace. Navigation does not reset application state.
