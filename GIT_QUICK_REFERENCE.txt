                              COMMON GIT WORKFLOWS
═══════════════════════════════════════════════════════════════════════════════════════

1️⃣ COMMIT & PUSH NEW CHANGES:
   ─────────────────────────────

   cd c:\Users\Maintenance\Downloads\offline_endurance_intelligence

   # Option A: Using automated script (PowerShell)
   PowerShell -ExecutionPolicy Bypass -File GIT_PUSH_COMMANDS.ps1

   # Option B: Manual commands
   git add -A
   git status --short                    # Review changes
   git commit -m "Your message here"
   git push origin develop

   # Option C: Specific file commits
   git add path/to/file.py
   git commit -m "Update: specific change"
   git push origin develop


2️⃣ CHECK STATUS:
   ──────────────

   git status                            # See all changes
   git log --oneline -n 5                # Last 5 commits
   git remote -v                         # Check remote URL
   git branch -v                         # Check branches


3️⃣ PULL LATEST CHANGES:
   ──────────────────────

   git fetch origin                      # Get latest metadata
   git pull origin develop               # Merge develop branch


4️⃣ MERGE TO MAIN (when ready):
   ───────────────────────────

   git checkout main                     # Switch to main
   git pull origin main                  # Get latest main
   git merge develop                     # Merge develop into main
   git push origin main                  # Push to main
   git checkout develop                  # Switch back to develop


5️⃣ CREATE FEATURE BRANCH:
   ──────────────────────

   git checkout -b feature/module-6-dashboard
   # Make changes...
   git add -A
   git commit -m "Feature: Add dashboard module"
   git push origin feature/module-6-dashboard
   # Create Pull Request on GitHub


6️⃣ VIEW COMMIT HISTORY:
   ────────────────────

   git log --oneline                     # Short log
   git log --oneline --graph --all       # Visual tree
   git show 7a3f88a                      # Show specific commit
   git diff HEAD~1 HEAD                  # Compare with previous


7️⃣ UNDO LAST COMMIT (if needed):
   ───────────────────────────────

   # Keep changes, undo commit
   git reset --soft HEAD~1

   # Discard changes completely
   git reset --hard HEAD~1


8️⃣ STASH WORK IN PROGRESS:
   ────────────────────────

   git stash                             # Save uncommitted changes
   git stash list                        # See all stashes
   git stash pop                         # Restore latest stash
   git stash drop                        # Discard stash

═══════════════════════════════════════════════════════════════════════════════════════

Problem: "fatal: not a git repository"

Problem: "Your branch is ahead of origin/develop by X commits"
Solution: git push origin develop


Problem: Cannot pull due to uncommitted changes
Solution: git stash (to save), then git pull, then git stash pop


Problem: Want to see what changed in last commit
Solution: git show HEAD or git diff HEAD~1 HEAD


Problem: Accidentally committed to wrong branch
Solution: 
  git reset --soft HEAD~1          (undo commit, keep changes)
  git checkout correct-branch
  git commit -m "message"
  git push origin correct-branch
