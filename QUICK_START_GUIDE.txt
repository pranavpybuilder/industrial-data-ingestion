🚀 CHOICE C: NSIS INSTALLER (Professional - 15 minutes)
================================================================================

First-Time Setup (One Time Only):

1. Install NSIS Compiler
   Visit: https://nsis.sourceforge.io/Download
   Download: NSIS 3.10
   Run installer (accept all defaults)
   Installation creates: C:\Program Files (x86)\NSIS\

Build the Installer:

2. Open Command Prompt/PowerShell
   Navigate to: cd C:\Users\[YourName]\Downloads\offline_endurance_intelligence

3. Compile Installer
   Run: "C:\Program Files (x86)\NSIS\makensis.exe" OfflineIndustrialIntelligence_Installer.nsi
   
   Output: OfflineIndustrialIntelligence_Setup_v1.0.0.exe (~30 MB)

4. Distribute Installer
   • Email to users
   • Host on internal server
   • Burn to CD/USB
   • Integration with MDM/SCCM
   
5. End Users Install
   • Double-click: OfflineIndustrialIntelligence_Setup_v1.0.0.exe
   • Follow standard Windows installer wizard
   • Application installed to Program Files
   • Shortcuts auto-created
   • Ready to use
   
Optional - Silent Installation:
   OfflineIndustrialIntelligence_Setup_v1.0.0.exe /S

🆘 QUICK TROUBLESHOOTING
================================================================================

Application doesn't launch?
   1. Verify Windows 10+ (64-bit)
   2. Check 2 GB RAM available
   3. Verify 500 MB disk space
   4. Run as Administrator
   5. Restart computer and try again

Installer says "Access Denied"?
   1. Right-click installer
   2. Select "Run as administrator"
   3. If still fails, restart computer

Dashboard doesn't load?
   1. Allow 5-10 seconds for first load
   2. Check system has sufficient RAM
   3. Update graphics drivers
   4. Restart application

Shortcut doesn't work?
   1. Verify it points to correct file
   2. Recreate shortcut manually
   3. Use Start Menu entry instead

For more help:
   → Read INSTALLATION_INSTRUCTIONS.txt (Troubleshooting section)
