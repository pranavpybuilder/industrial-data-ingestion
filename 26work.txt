WHEN TO USE ML vs RULES:
───────────────────────

USE RULES for:
  ✓ Clear thresholds (temperature > 90°C)
  ✓ Deterministic maintenance heuristics (PM overdue by X days)
  ✓ Binary decisions (this IS a valid value / this ISN'T)
  ✓ Explainability matters (users must understand why)
  
USE ML for:
  ✓ Patterns in complex multi-dimensional data
  ✓ Anomalies that don't fit simple thresholds
  ✓ Time-series forecasting (predict next value)
  ✓ Discovering hidden correlations

IN THIS PROJECT:
  • Module 3 (Rules): ~70% of insights (primary engine)
  • Module 4 (ML): ~30% of insights (secondary, enhanced detection)
  • Module 5: Combines both equally for final output
