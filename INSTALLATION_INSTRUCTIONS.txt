METHOD 3: PROFESSIONAL NSIS INSTALLER (Enterprise)
================================================================================

For professional distribution and enterprise deployments.

PREREQUISITE: NSIS Installation
   
   What is NSIS?
   - Nullsoft Scriptable Install System
   - Industry standard for Windows installers
   - Used by Firefox, 7-Zip, WinRAR, etc.
   
   How to Install NSIS:
   
   Option A: Automatic installation (if available)
   1. Download from: https://nsis.sourceforge.io/Download
   2. Run installer (accepts all defaults)
   3. Installer will be at: C:\Program Files (x86)\NSIS\makensis.exe
   
   Option B: Via Chocolatey (if you have it)
   $ choco install -y nsis
   
   Option C: Manual via PowerShell
   $ iwr -Uri "https://sourceforge.net/projects/nsis/files/NSIS%203/3.10/nsis-3.10-setup.exe" -OutFile "$env:TEMP\nsis.exe"
   $ & "$env:TEMP\nsis.exe" /S

Step 1: Compile Installer
   Location: OfflineIndustrialIntelligence_Installer.nsi
   
   Option A: Using File Explorer
   - Right-click .nsi file
   - Select: Compile NSIS Script
   
   Option B: Using Command Line
   $ "C:\Program Files (x86)\NSIS\makensis.exe" OfflineIndustrialIntelligence_Installer.nsi
   
   Option C: Using PowerShell
   $ & "C:\Program Files (x86)\NSIS\makensis.exe" /V2 OfflineIndustrialIntelligence_Installer.nsi

Step 2: Output
   - Generates: OfflineIndustrialIntelligence_Setup_v1.0.0.exe (~30-35 MB)
   - Ready for distribution

Step 3: Distribution
   - Email as attachment
   - Host on internal server
   - Include in CD/USB distribution
   - Distribute via MDM/SCCM

Step 4: End-User Installation
   - User receives: OfflineIndustrialIntelligence_Setup_v1.0.0.exe
   - Double-click installer
   - Follow wizard (standard Windows installer look)
   - Application installs to: C:\Program Files\OfflineIndustrialIntelligence
   - Desktop & Start Menu shortcuts automatically created
   - Ready to use immediately

Step 5: Silent Installation (IT Use)
   For mass deployment or scripted installation:
   
   $ OfflineIndustrialIntelligence_Setup_v1.0.0.exe /S
   
   This performs installation silently with no user interaction.

TROUBLESHOOTING
================================================================================

Application Won't Start
- Solution: Verify all files in installation directory exist
- Check: C:\Program Files\OfflineIndustrialIntelligence\
- Re-run installer to repair

"Missing DLL" Error
- This should NOT happen if installed correctly
- All DLLs are bundled in the executable
- Delete installation and reinstall fresh

Dashboard Not Loading
- Allow 5-10 seconds for first-time load
- Check system RAM (minimum 2GB required)
- Verify graphics drivers are up to date

Export Feature Not Working
- Verify write permissions in Documents folder
- Check available disk space
- Try exporting to different location

Application Crashes
- Note the error message
- Try Safe Mode installation (no GPU acceleration)
- Check Windows Event Viewer for details
